弹层全局规范

层级 / 尺寸档 / 统一解剖 / 关闭返回链 / 红点与安全区

五级弹层（本项目唯一分层口径）

L1主页面：战斗 / 英雄 / 商店 / 玩法 / 基地z 8500
L2全屏二级页：装备强化、英雄养成、工坊、副本、派遣、改装z 8600
L3二级弹窗：邮箱、公告、任务、详情、图鉴、设置z 8700
L4半屏抽屉：编队、批量操作、快速选择z 8800
L5结果演出层：招募揭晓、战斗结算、升级三选一z 8900
  • 同一时刻只允许一层弹窗：新开先关旧（就地替换），不做无限套娃。
  • L2/L3/L4 互斥；弹窗里再开弹窗统一走「替换 + 左上返回」，返回链最多 2 跳。
  • L5 独占：进入时屏蔽返回，必须走自身 CTA 离开。

弹窗统一解剖（五段式）

1头部区（固定）高 34~44
标题 / 品质头 / 横幅；右上角关闭 ✕
2说明与页签区（固定）高 20~30
副标题、? 帮助、2~4 枚页签
3内容滚动区（唯一滚动体）flex:1
列表行 / 属性行 / 网格；底部渐隐提示可滚
4主 CTA 区（固定）高 46~56
单按钮居中 / 双按钮并排；上方 1px 分隔线
弹窗五段式：2 固定 + 1 滚动 + 1 CTA（+ 顶部安全余量）

滚动与固定区规则（避免"CTA 被滚走"）

  • 弹窗内只有内容区滚动；头部与 CTA 恒固定（flex:none + 内容 flex:1 + overflow:auto）。
  • 窗口高度一律用上下边距 + 自适应，不写死高度；内容不足时弹窗收缩而不是留白。
  • 滚动区底部加 16px 渐隐，明确"下面还有"。
  • 切页签保留滚动位置；重新打开同一弹窗回到顶部。
  • 列表 ≥ 8 行必须给滚动条或渐隐；行内不做横向滑动（避免与页面横滑冲突）。

关闭与返回链（全项目统一）

关闭 ✕固定右上角，尺寸 ≥ 24（1080 稿 88），任何弹窗不得省略
返回 ◀L2 全屏页固定左上角；从 L3 详情钻取进来时，左上显示返回、右上不再重复 ✕
遮罩点击L3/L4 可关闭；L5 结果层不可（防误触丢掉奖励）
系统返回等价于当前层的关闭/返回；L5 忽略
关闭后落点回到打开它的那一层原状态（滚动位与页签保持）

红点 / 角标 / 状态

  • 红点挂元素右上角外缘（-4px 溢出），直径 ≥ 11（1080 稿 40）。
  • 数量角标只在"可领取数量"与"材料差额"上出现，形状为胶囊、底色深、字色亮。
  • 可领取/未读统一红色；可升级统一金色；已过期/已领完统一置灰 + 降透明。
  • 禁用态按钮保持形状不变，只降对比并去掉描边高光，不改文案（避免布局跳动）。

安全区与微信胶囊（红线）

  • 胶囊禁入区 ≈ 右上 90×34 外扩 20，弹窗关闭按钮与底部 CTA 均不得落进去。
  • L2 全屏页顶部留 60（状态栏+胶囊带）；L3 居中弹窗顶部起点 ≥ 78。
  • 底部 CTA 区抬高 + Home 条高度；L2 底部操作栏同理。

热区与点击流

  • 最小热区 88×88（1080 稿）；列表行整行可点，行内动作钮独立热区且不冒泡。
  • 弹窗打开不做入场动画的层级变化（布局稿要求：位移不超过自身高度 8%）。
  • 所有"一键 X"按钮语义 = 批量执行可执行项 + 结果 toast，无二次确认。
01

列表型弹窗（M 档 · 对照图 1「先锋官邮箱」）

横幅头 + 可滚列表 + 底部固定「一键领取」+ 过期倒计时列
1头部用「横幅」而不是细标题条

列表型弹窗的主要任务是"清空可领内容"，头部做成 44 高横幅（标题 + 右侧插画位），与页面顶栏形成视觉断点；关闭 ✕ 仍固定在本体右上，不压横幅文字。

2列表行三段式：图标 34 ｜ 主副文案 ｜ 状态/动作

第一行标题（单行省略），第二行左侧"来源/日期"，右侧状态列：倒计时用暖色、过期用红色、无附件用灰字。整行可点＝打开详情/展开；行内动作钮独立热区、不冒泡。

3底部 CTA 固定 + 状态注脚

「一键领取」常驻底部（永不随列表滚走），数量写进按钮文案（一键领取（2））；按钮下方一行小字承担规则说明（过期自动删除 / 活跃进度），替掉原本塞在列表里的说明行。

4红点位置统一

行的未读红点挂在行块右上外缘（不是图标上）；入口红点由"存在可领取/未读"驱动，一键领取执行后同步熄灭（含页签与入口）。

5空态与满态

空列表时：滚动区居中显示"暂无新邮件" + 一行指引（去战斗领取奖励）；CTA 变禁用态但保留占位，避免打开/关闭时高度跳动。

6点击流

入口(顶栏邮箱/玩法页) → L3 弹窗展开 → 行点击看详情（就地替换）→ 一键领取 → toast「已领取 N 件」→ 关闭回到原页面原位置

02

详情型弹窗（L 档 · 对照图 2「宝石属性 / 装备属性」）

品质色头部 + 2 枚页签 + 属性行（带行内动作）+ 底部单一去向 CTA
1品质色头部 = 身份牌

头部用品质底色 + 左上阶标 + 图标 + 名称 + 3 条短属性。品质底色是语义色（本稿只用色带位置，具体色值留给美术任务）；阶标（1阶）永远贴图标左上，不写进标题文字。

2Tab 紧贴头部下方，两枚最佳

详情弹窗 Tab 上限 4 枚（宝石属性/装备属性/词条/来源）。切页签只换内容区，头部保持不动；选中态用下划线 + 高亮，避免整块变色导致头重脚轻。

3属性行 = 图标 + 文案 + 行尾动作

行尾动作固定两种：图标钮（查看/展开，26 宽）与文字钮（卸下/镶嵌，金色描边）。空槽位用虚线行 + 蓝色「镶嵌」，与已填行的金色动作形成"换/加"对比。

4底部 CTA 是"下一步"，不是"关闭"

详情弹窗底部只放一个去向（装备锻造 / 前往提升 / 前往获取），关闭交给右上 ✕。CTA 下方一行小字解释副作用（卸下宝石自动回收）。

5长文案换行规则

属性文案最多 2 行，超出省略并靠"展开阅读"承载；数字（+12%）永远高亮且不换行。行高随文案自适应，行与行之间固定 7 间距。

6点击流

背包/槽位点击 → L3 详情（默认"主视角"页签）→ 行尾卸下/镶嵌 → 就地刷新行 → 底部 CTA 钻取到 L2 养成页（左上出现返回）→ 返回落回详情

03

确认型小弹窗（S 档 · 对照图 3「一键合成」）

窄弹窗 + 说明行（? 帮助）+ 素材网格 + 单个动作 CTA
1S 档只有纵向三行内容

宽度固定 200（1080 稿 720），内容最多 标题 + 说明 + 3 行信息；素材预览用网格（5 列优先级最高，视数量降为 4/3 列），网格不超过 2 行，更多走"×N"角标。

2说明行 + ? 帮助

合成/转化类必须在标题下给一行结果说明（"以下物品将合成新物品"），右侧 ? 指向概率/规则详情；规则细节不要写进正文，避免弹窗变高。

3单动作 CTA vs 双按钮

可逆/正向操作（合成、强化、领取）用单个居中大按钮；不可逆或消耗型（分解、下阵、购买）用双按钮，取消在左、确认在右，且确认语义用危险色或金色区分。

4禁用态与不足态

材料不足时按钮禁用于原位，并在按钮下方小字直接给出差额（"还差 3 颗强化石"），点击禁用按钮 → toast 指出缺口，不打开新层。

5点击流

工坊「一键合成」→ S 弹窗预览 → 合成 → 结果 toast + 网格就地刷新 → 关闭回到工坊原滚动位

04

全屏二级页（XL 档 · 对照图 4/5「装备强化 / 升品」）

展示台 + 等级与属性对比块 + 消耗行 + 双 CTA + 槽位条 + 底部操作栏
1顶部展示台（展示对象 = 本次操作主体）

纵向配比 3 : 4 : 3（展示 : 对比 : 底栏）。展示台只放：图标（带阶标）、名称、一行副信息；不放按钮，避免与底部 CTA 抢焦点。

2对比块是"升级类"的通用件

等级对比（8级 ➜ 9级）与属性对比（+16 ➜ +18）用同一个 cmpBox：头部小标题 + 内容行；左值弱化、右值强调、中间箭头。

3消耗行：数量写成「持有/需求」

消耗物统一 图标 + 持有/需求，差额不足标红、充足标绿；一行最多 3 个消耗项，更多折到"更多材料"入口。

4双 CTA 贴着消耗行，在槽位条之上

「强化」＝单次、「一键强化」＝自动执行到资源上限；两枚并排等宽、一次一色（绿＝常规、金＝批量），位置固定在消耗行下方、槽位条上方。禁用态同时置灰并保留占位；长按单次按钮进入连续强化。

5槽位条 = 就地换目标

底部槽位条常驻，当前编辑槽高亮；点其它槽＝换对象但不离页（不做返回），红点表示该槽可强化。槽位顺序与英雄页装备格完全一致，避免玩家重新建立空间记忆。

6底部操作栏：左返回 + 右页签

左圆返回按钮固定；右侧 2~4 枚页签承载同级子页（强化/升品，技能/核心/天赋/武器）。页签即层级，不再向上叠弹窗。

7点击流

英雄页/背包 → L2 全屏页（左上返回）→ 槽位条换目标 → 强化 → 数值就地跳动 + 槽位红点更新 → 返回落回英雄页原滚动位

05

结果演出层（L5 · 独占 · 不可遮罩关闭）

招募揭晓 / 战斗结算 / 升级三选一：全屏、强反馈、单一出口
1L5 独占：不出系统返回、不可遮罩关闭

结果层必须由玩家点自己的按钮离开（返回/下一关）。防止误触丢失展示信息，也避免"未领取就退出"的纠纷。

2出口数量固定 2 个

招募：再抽 / 返回；结算：下一关 / 再来一次。危险或消耗动作不放结果层，避免在情绪高点误消费。

3局内三选一用纵向卡片

区别于局外的横向卡面：局内卡片纵向排布在拇指区，单卡 = 图标 + 名称 + 一行效果 + 行尾选择；刷新/锁定独立成行，不挤占三张卡的点击区。

4与 L3/L4 的关系

L5 打开前强制关闭 L3/L4（结果来自那些操作），关闭后不自动恢复原弹窗，回到其所属页面。
