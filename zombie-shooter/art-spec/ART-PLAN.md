# 游戏美术资源阶段计划（ART-PLAN）

> 2026-09-20 制定。背景：一~四轮零散生图验证了方法（整表一次成型 + 基准图锚定 + 短 prompt），
> 但产出零散、游戏内 emoji 与贴图混排、风格未成体系。本计划按「玩家视线覆盖率」把美术资源
> 分五个阶段**整族重做**：任一阶段完成即整族替换上屏，游戏全程可玩、可回退。

## 0. 总纲

- **方法（已验证，保留）**：一次生成一族（2K 大表 15~25 格）→ gpt-image-2 **edit 模式**锚定
  基准图2 → prompt 只报槽位名、不指定形状颜色 → `slice_sheet.py` 切片落盘 → 换图不换 key。
  细节见 [STYLE-SPEC.md](./STYLE-SPEC.md) §8。
- **风格锚**：`game_art_benchmark2.png`（末日军武风）为唯一基准；casual 基准图仅作面板/按钮参考。
- **放弃策略（冻结不清盘）**：现有在库图一律降级为「临时版」继续服役；各阶段用成套新图
  **整族替换**（同名覆盖即时生效，缺图自动回退占位兜底）。不做一次性清盘——游戏观感倒退、
  无收益；若确要回占位，按 git 历史检出对应 textures 即可，随时可执行。
- **每阶段收尾（顺序固定）**：生成 → 切片落盘 → MANIFEST 登记 → 构建 → check 链
  （tc / check-ux-refactor / check-art-manifest）→ 新端口烟测截图 → 提交推送
  （**一族一个 commit**，可整体回退）。

## 2. 阶段计划

### P0 规范与工具固化（半个轮次，不生图）

| 任务 | 说明 |

| 打基线 tag | 当前全部在库图标记「临时版」，现状即基线，可随时对比 |

**验收**：check 链全绿。

### P1 战斗主循环（玩家 100% 视线所在，最高优先）

| 表 | 内容（prompt 只报名字） | 落位 |
|---|---|---|
| 表1 战斗场景族 | 主角运兵车（车尾/受损两态）、路面、护送页场景图、战斗远景 | scenes/vehicle_tail、scenes/road、scenes/escort |
| 表2 怪物族 | 5 现役怪单图整表重生成（野猪/犬/熊/鹰/石猴，对齐基准图2） | monsters/boar · dog · bear · eagle · stoneape |

**决策点（P1 开工前定）**：12 帧行走序列为 AI 视频抽帧，动作质量高但风格与生图异源。

**验收**：进战烟测三截图（开局 / 中盘 / 怪潮），§6 清单过一遍。

## 3. 共性纪律（每阶段强制）

1. 一族一表一次成型；prompt 只报槽位名；绿幕底 + 间隙；2K 起步。
2. 出图先目检与基准图2并排过 §6 清单，再切片。
3. 换图不换 key；新 key 先登记 AssetLib MANIFEST（文件可后到）。
4. 同族 emoji 一并替换收口，不让 emoji 与贴图长期混排。
5. 一族一个 commit：素材 + meta + 接线 + 规范更新同包，可整体回退。

## 4. 风险与决策点

| 风险/决策 | 处理 |
|---|---|
| 怪物走帧风格混源 | P1 决策：推荐保留走帧（动作资产），单图重生成拉近 |
| 人物整表一致性 | 2×2 大格 + 2K；出图后四张并排比对再切 |
| 九宫格面板契约 | 四角 24px 等宽，量测后再配 9-slice；不达标重出 |
| 长条件（绶带/横幅）变形 | P0 工具补课后用 `--rect` 自然比例切片 |
| 每阶段周期 | 约 2~4 张表 + 1 次构建，单轮可完成；不跨轮积压 |
