> 分工：**用户按本清单手动生图**，交付到 `D:\qoder workspace\AIG\gen-output\r1-fantasy\`（按 key 命名文件）；
> AI 负责后续全部落地动作：抠像 / 切片 / 压体积 / 落盘进包 / 构建与验证链 / 走帧暂停播放的代码口径。
> **可分批交付**：出一批丢一批，到一批上一批，不用攒齐。

## 总规矩（每批都适用）

1. **画风不变，换的只是题材**：跟现役件同一套画法。**内容件（场景/人物/怪物/弹道/据点小图）是
   欧美写实厚涂游戏插画**（基准图2 角色行那种画法，不是休闲 Q 版）；**图标表（批 5）才是
   粗描边休闲卡通**（§1/§8 口径）。风格锚 = 批 0 的奇幻基准图，之后每条 prompt 都带它做参考图。
2. **绿幕出图**：一切要透明的件（人物/怪物/道具/图标）用纯绿底 `#00FF00`，不用自己抠像，
   我用 `tools/chroma_key.py` / `slice_sheet.py` 抠。整幅底图（场景/照片）直接出，不带绿幕。
3. **换图不换 key**：表里的 key 就是最终落盘路径，交付文件直接按 key 命名（如 `scenes/road.jpg`）。
4. **体积上限 = 现文件字节数**（预算 26.81/27.0MB 只许变小）；我管线里还会再压一轮（底图 JPG、切片件 256 色）。
5. 验收看 STYLE-SPEC §6 九条，素材表版主要过 5/6/8/9。
6. **BOSS 不单独出图**：复用怪图放大（`Enemy.isBoss` 同纹理缩放）。
7. prompt 写法：**图标类照 §8 只报功能名不带形象**（批 5/批 7），风格交给基准图锚定；
   内容件（批 0~4、批 6）的形象与构图本身就是契约，提示词里写清楚（见各批「参考提示词」）。
   绿幕必须点名 `#00FF00`。

## 参考提示词怎么用（先读这段）

- **能垫图就垫图**：支持参考图/垫图的工具（即梦、gpt-image edits 等）一律把批 0 奇幻基准图
  当参考图，同批件共用它，画风就不会漂；纯文字工具直接用下面写好的中文 prompt（风格已写进句子）。
- **图标/小件一次成表**：批 5、批 7 一次生成一整张（§8 教训：逐张生必漂移）。
- **绿幕件点名 `#00FF00`**；底图件（批 1/批 2、批 3 的指挥官与三联像）整幅直接出图，不要绿幕。
- **合规雷区**：「三名××并肩合影」「现实军衔头衔」这类措辞部分生图工具会以合规理由拒单；
  多人像写成「一行三个从左到右依次是：…」的素材表措辞，头衔用「将军/教官」这类泛称即可。
- 交付像素可整倍放大（我统一缩），但**长宽比例别变**；出完按 key 丢 `gen-output\r1-fantasy\`。
