## 总规矩（每批都适用）

1. **画风不变，换的只是题材**：仍是 STYLE-SPEC §1 的 casual 高饱和卡通（粗描边、大圆角、厚体积、软明暗）。
   风格锚 = 批 0 的奇幻基准图，之后每条 prompt 都带它做参考图。
2. **绿幕出图**：一切要透明的件（人物/怪物/道具/图标）用纯绿底 `#00FF00`，不用自己抠像，
   我用 `tools/chroma_key.py` / `slice_sheet.py` 抠。整幅底图（场景/照片）直接出，不带绿幕。
3. **换图不换 key**：表里的 key 就是最终落盘路径，交付文件直接按 key 命名（如 `scenes/road.jpg`）。
4. **体积上限 = 现文件字节数**（预算 26.81/27.0MB 只许变小）；我管线里还会再压一轮（底图 JPG、切片件 256 色）。
5. 验收看 STYLE-SPEC §6 九条，素材表版主要过 5/6/8/9。
6. **BOSS 不单独出图**：复用怪图放大（`Enemy.isBoss` 同纹理缩放）。
7. prompt 写法照 §8：**只报功能名不带形象**，风格交给基准图锚定；绿幕必须点名 `#00FF00`。
