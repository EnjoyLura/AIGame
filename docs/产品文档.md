# 《末日航线》产品文档

> **一句话定位**：末日护送题材的竖屏自动战斗微信小游戏——指挥四名英雄守护运输载具，抵御变异怪物的围攻，玩法对标《向僵尸开炮》。
> **当前状态**：基础版工程骨架已完成并实测可玩（本文档第 6 节）。

---

## 1. 世界观

未来世界科技爆发但环境恶化，地球不再宜居，野外充斥变异怪物：**发狂的异化狗、直立行走的熊、长獠牙的野猪、饥饿发狂的老鹰**……人类各势力组建守护队，部分人进化出**风、雷、冰、火**超自然力的超能力者。

玩家扮演末日**指挥官**，负责各人类城市之间的能源与物资运输：守护陆地**货车**、水上**船**、空运**飞机**。怪物从后方不断追赶、并不时从侧面伏击——指挥官指挥最多 **4 名英雄**护卫载具，阻止运输线被摧毁。

## 2. 核心循环

```
局内（单局 3~5 分钟）                局外（长线养成）
┌─────────────────┐              ┌─────────────────┐
│ 护送载具前进      │              │ 英雄升级/升星     │
│ ↓ 击杀怪物掉经验  │              │ 英雄装备强化      │
│ ↓ 升级三选一强化卡 │   胜利奖励 →  │ 载具解锁/改装     │
│ ↓ 波次推进/章节奖励│              │ 技能/大招数值成长  │
│ └→ 载具被毁=失败  │              └─────────────────┘
└─────────────────┘
```

## 3. 英雄系统（首发 8 名）

### 3.1 人类英雄（枪械，普攻即核心输出）

| 英雄 | 武器 | 攻击特征 | 定位 |
|---|---|---|---|
| 步枪手 | 步枪 | 单发自动瞄准，节奏稳定 | 持续输出 |
| 狙击手 | 狙击枪 | 高伤慢速、超远射程 | 单体爆发 |
| 激光手 | 激光枪 | 跟踪锁定、持续灼烧伤害 | 持续输出/单体 |
| 辐射枪手 | 辐射枪 | 弹速极快、**穿透**多个敌人 | 群体伤害 |

### 3.2 超能力者（法术，阶段二实装）

| 英雄 | 能力 | 攻击特征 | 定位 |
|---|---|---|---|
| 烈焰 | 火球 | 爆炸溅射 | 群体伤害 |
| 霜华 | 冰锥 | 减速控制 | 辅助控制 |
| 疾风 | 风刃 | 多段快速切割 | 持续输出 |
| 雷霆 | 连锁雷电 | 弹跳转移目标 | 群体伤害 |

每个英雄独立拥有：**普攻 / 技能 / 大招** 三个战斗维度；定位覆盖单体爆发、持续输出、群体伤害、辅助增益。

## 4. 局内战斗规则

- 上阵最多 **4 名英雄**，分散站在运输载具车尾自动战斗，互不干扰索敌。
- 画面只露出**载具尾部**（横贯整个屏幕底部），路面持续向后滚动，营造载具向前开的感觉。
- 怪物**主要从屏幕上方不断追近车尾**（追赶），**少部分从两侧**出现伏击（抄近路少走距离），
  追到车尾后啃咬载具耐久。
- 击杀怪物**随机掉落经验**，自动拾取；经验满 → 英雄团队升级 → 弹出**随机增益卡片三选一**。
- 增益卡片**强化单个英雄**的普攻/技能/大招（如：步枪手·射频强化 +15%）。
- **载具耐久归零 = 护送失败**；撑过全部波次 = 护送成功。
- 波次/章节推进：不同城市路线切换载具（货车 → 船 → 飞机），怪物种类与强度递进。

## 5. 养成系统（长线）

| 系统 | 内容 |
|---|---|
| 英雄养成 | 等级、升星，提升普攻/技能/大招基础数值 |
| 英雄装备 | 每英雄独立装备槽，词条掉落 |
| 运输载具 | 耐久/护甲/撞角等改装，载具外观收集 |
| 技能数值 | 普攻·技能·大招独立配置表，策划 Excel 导表驱动 |

## 6. 美术风格

- 参考对标：《向僵尸开炮》——竖屏 720×1280、俯视视角公路推进、欧美卡通描边风、高饱和色块 + 明快特效。
- 场景按章节切换：废土公路（货车）/ 污染河道（船）/ 风暴航线（飞机）。
- 制作管线：AI 出概念图 → PS 修分层；角色 Spine 骨骼动画；特效序列帧 + 粒子。
