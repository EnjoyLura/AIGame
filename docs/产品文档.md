# 《王国守望》产品文档

> **一句话定位**：剑与魔法题材的竖屏自动战斗微信小游戏——扮演王国的指挥官将军，指挥英雄驻守据点，抵御哥布林、兽人、恶魔等大军入侵，守护各处领地，玩法对标《王国保卫战》。
> **当前状态**：基础版工程骨架已完成并实测可玩（本文档第 7 节）。
> **口径说明**：本文档是 2026-09-24 世界观改版后的设定真源。工程内 UI 文案、关卡/怪物/英雄命名与美术资源**仍为旧《末日航线》口径，本轮全部未动**，待迁移点见第 9 节。

## 1. 世界观

剑与魔法的奇幻大陆。黑暗势力卷土重来：**哥布林**部落打头阵，**兽人**军团践踏平原，**恶魔**大军自深渊涌出——王国边境的村镇、要塞与圣地接连告急。

玩家扮演王国的**指挥官将军**，奉命驰援各条防线：在据点上排兵布阵，指挥最多 4 名英雄驻守，抵御一波波从道路推进的敌军。敌军的目标只有一个——攻破据点大门。**据点陷落，领地易主**；守住全部攻势，领地便安然无恙。

## 2. 核心循环

```
局内（单局 3~5 分钟）                局外（长线养成）
┌─────────────────┐              ┌─────────────────┐
│ 据点迎击来犯敌军   │              │ 英雄升级/升星     │
│ ↓ 击杀敌人掉经验   │              │ 英雄装备强化      │
│ ↓ 升级三选一强化卡 │   胜利奖励 →  │ 据点工事/城防强化  │
│ ↓ 波次推进/章节奖励│              │ 技能/大招数值成长  │
│ └→ 据点陷落=失败  │              └─────────────────┘
└─────────────────┘
```

## 4. 局内战斗规则

- 上阵最多 **4 名英雄**，驻守在屏幕底部横贯的**据点城墙**上自动战斗，互不干扰索敌。
- 战场是**静止的**：背景不再模拟行进路面，据点固定在画面底部，没有行进感演出。
- 敌军**主要从屏幕上方沿道路逼近城墙**（正面进攻），**少部分从两侧**绕行突袭（抄近路）；
  逼近城墙后猛攻**据点耐久**。
- 击杀敌军**随机掉落经验**，自动拾取；经验满 → 英雄团队升级 → 弹出**随机增益卡片三选一**。
- 增益卡片**强化单个英雄**的普攻/技能/大招（如：弓箭手·穿透箭雨 +15%）。
- **据点耐久归零 = 防守失败**；撑过全部波次 = 据点守住，护送成功改为**领地守住**。
- 章节/据点推进：不同领地切换据点场景（古道、巨桥、废墟、要塞、深谷），敌军种类与强度递进。
